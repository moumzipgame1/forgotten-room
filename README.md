# 망각의 방 (忘却)

기억을 잃고 지하 연구시설에서 깨어난 주인공이 열 번째 방의 진실에 다가가는 **텍스트 미스터리 어드벤처**입니다.
조사 → 아이템 조합 → 번호 퍼즐 → 선택지로 진행되며, 전 10챕터와 엔딩 4종(히든 포함)이 있습니다.

> 스포일러 주의: 단서 노트와 엔딩에 줄거리의 핵심이 드러납니다.

## 플레이

- GitHub Pages 주소: `https://<사용자이름>.github.io/<저장소이름>/`
- 로컬 실행: `index.html`을 브라우저로 열면 됩니다. (설치·서버 불필요, 모바일 지원)

## 조작

1. **조사하기** 버튼으로 사물을 살펴 단서와 아이템을 얻습니다.
2. 가방의 아이템을 눌러 선택한 뒤 조사 대상을 누르면 사용합니다.
3. 아이템 두 개를 차례로 누르면 조합합니다.
4. 막히면 오른쪽 위 **힌트**를 누르세요.
5. 진행 상황은 브라우저에 자동 저장되며 **이어하기**로 불러올 수 있습니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 게임 전체 (HTML + CSS + JS + 삽화 포함, 단일 파일) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서비스하도록 하는 빈 파일 |

## 크레딧

- 기획·구현: 이 저장소의 제작자
- 삽화: AI 이미지 생성으로 제작
